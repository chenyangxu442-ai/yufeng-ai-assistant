# 0.5.0 完整使用流程

用户授权：把此前建议的方向一次纳入同一版。现有0.4.0只是下载安装器和538条角色/技能说明库，不能将它们表述为已实测的自动化工具。

## 验收

1. 场景向导提供写材料、表格处理、网页制作、文件整理。收集目标、材料和限制，生成可直接用于Harness的任务说明，有明确开始入口；如果没有可验证的Harness任务API，使用复制任务说明并打开助手，界面清楚说明还需粘贴发送，不伪造自动执行。
2. 能力套餐提供办公、求职、网页三个预设，明确展示选中技能、用途、任务示例和依赖，只安装用户选定套餐。技能发现通过不等于效果验证，状态须准确。
3. 环境检测按场景检查托管Node、Git、Python。准备按钮确实启动受信任的官方安装流程或经校验的私有运行环境，执行后重新检查。不修改全局PATH，不凭空声称完成安装。
4. 文件工具使用原生目录选择限定范围，预览后用户明确点击执行，保存撤销记录。拒绝覆盖、路径穿越、链接逃逸；撤销前检查内容是否变化，保护用户后续编辑。恢复过程可以报告冲突，不删除用户数据。
5. 费用管家提供输入/输出token与单价估算、预算提醒，所有估算明确标记。没有真实usage来源就显示未接入实际用量，不能显示假账单或将提醒说成硬性额度限制。默认价格不使用过期猜测。
6. 任务记录保存准备过的任务、使用时间和可复用参数，重启后能恢复；不保存API密钥。重复使用进入同一个场景流程，不只是展示列表。
7. 能力包支持版本说明、受控包导入、更新前校验、托管文件更新和回退。更新/回退保护修改过的文件与未托管的同名内容，不允许通过包名称/路径越界，不将任意远程代码自动执行。
8. 中文界面提供可见结果和失败提示，各项流程连通。测试验证实际状态改变、文件恢复及冲突、任务持久化、价格计算、技能包更新回退和安全边界。保留旧回归检查并生成可安装产物。

## 边界

继续使用当前已验证Harness版本，不为新功能无理由升级依赖；用户虚拟机关闭，不能声称新版本已在空白机完成端到端实测。源Skill搜索项目保持只读。不部署或发布任何服务。
